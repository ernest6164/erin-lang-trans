📦 3. 디스코드 서버용 이모지 팩 (.zip) 다운로드 & 서버 등록 가이드
128×128 정사각형 PNG · 256KB 이하 규격 완벽 준수
외곽선 스타일 · 전체 40종 이모지 팩 (`erin_discord_emoji_outline_40.zip`)
기본자음(14) + 쌍자음(5) + 기본모음(10) + 복합모음(11) = 총 40개 (기본 서버 무료 슬롯 50개 이내)
STEP 1 이모지 팩 ZIP 다운로드 & 압축 해제
위 버튼으로 서버 슬롯 여유에 맞는 ZIP 파일(40종 / 31종 / 26종)을 받아 폴더에 압축을 풀어주세요. 모든 파일명이 erin_r.png(ㄱ), erin_rr.png(ㄲ), erin_o.png(ㅐ), erin_oo.png(ㅒ)처럼 영문 소문자 규칙으로 지정되어 있습니다.
STEP 2 디스코드 서버 설정 → 이모지 일괄 업로드 (10초 완료)
디스코드 좌측 상단 서버 이름 클릭 → 서버 설정(Server Settings) → 이모지(Emoji) → 이모지 업로드(Upload Emoji) 버튼을 누른 뒤, 압축 푼 폴더의 PNG 파일들을 Ctrl+A(전체 선택)하여 한 번에 열기 하세요.
💡 팁: 파일명이 곧바로 이모지 이름(:erin_r: 등)으로 자동 등록되므로 이름을 일일이 수정할 필요가 전혀 없습니다!
STEP 3 한국어/영어 → 디스코드 이모지 채팅 전송
상단 좌측의 한국어/영어 입력창에 원하는 문장을 입력하고 📋 전체 코드 복사를 눌러 채팅창에 붙여넣으면(Ctrl+V) 에린어 이모지 문장으로 전송됩니다! 한 메시지당 이모지가 27개 이하이고 일반 문자가 없으면 디스코드에서 점보 크기(크게 보기)로 출력됩니다.
STEP 4 디스코드 이모지 채팅 → 한국어/영어로 역해독
다른 서버원이 올린 에린어 이모지 메시지를 드래그하여 복사한 뒤, 상단 좌측의 디스코드 이모지 코드 입력창(또는 한국어 입력창)에 그대로 붙여넣으면(:erin_v::erin_o:... 및 <:erin_v:ID> 모두 호환) 즉시 한국어와 영어로 역번역됩니다!
⚠️ 실험적 기능 (Beta) 안내 — 스크린샷 에린어 해독(OCR)은 현재 Beta(실험적 기능)입니다. 인게임 배경 조명·무늬·기울기·해상도 등에 따라 인식이 잘 동작하지 않거나 일부 글자가 오인식될 수 있으니, 우측의 글자 칩을 클릭해 수동 교정 기능을 함께 활용해 주세요.

📌 ㅐ와 ㅔ의 맞춤법 차이
직관적으로 ㅏ + ㅣ로 만드는 ㅐ와 달리, ㅔ는 ㅓ + ㅣ가 아니라 ㅣ + ㅏ로 만듭니다. (해독 시 가장 걸리기 쉬운 포인트!)
📌 ㅒ와 ㅖ의 오른쪽 위 반점(Tick)
자음 된소리(ㄲ, ㄸ, ㅃ, ㅆ, ㅉ)를 표현할 때처럼, ㅒ와 ㅖ도 각각 ㅐ와 ㅔ의 오른쪽 위에 반점을 찍어 표현합니다.
🔠 에린어 문자 변환표 (`data/` 추출 리소스 · 클릭 시 원문에 입력) 모음은 상하/좌우 대칭 구조이며, 카드를 클릭해 에린어를 직접 입력·해독할 수도 있습니다.
